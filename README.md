# Alumni Campus Pop — 試験公開

青山学院大学OBのキャリアストーリーを紹介する採用LPです。

## 公開構成
index.html / style.css / main.js と、同じ階層の画像・フォントをGitHub Pagesのmainブランチ、rootから配信します。
Python標準サーバー等で確認できます。追加依存やビルドは不要です。

## ヒーロー写真
元写真: https://www.baudroie.jp/control/img/bg-int01-mv.jpg
背景と椅子のみをアルファマスクで除去。元解像度の切抜きはRGB差分0、目線・顔・衣服は変更していません。表示用はLanczos補間で2倍に拡大し、生成による細部の補完は行っていません。
その他セクションは承認済み合成デザインを使用しています。

相談URLは最終確認中のため案内のみ表示し、個人情報の送信・通知は行いません。試験公開ページはnoindex,nofollowを指定しています。
写真・イラスト等の利用権はそれぞれの権利者に帰属します。外部フォント・アイコンのライセンスは同梱しています。
