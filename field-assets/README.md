# Field-specific career LPs

Additive science (`../rikei/`) and humanities (`../bunkei/`) variants of the approved university career LP. The original root page is unchanged.

Publish directly with GitHub Pages; no build step required. Shared fonts, CSS, JavaScript and illustrations are local to this repository. Hero illustrations were generated specifically for these variants.

Dedicated L Message attribution is configured for both variants (2026-10-28). Each page's three external LINE CTA buttons (desktop navigation, hero, and closing CTA) use its own issued URL. The mobile menu's `#register` fragment is unchanged.
